# 代码是唯一真相，图只是投影

Call 的图永远从代码推导（LSP 调用层级 + tree-sitter），`.call/` 只存布局、提示词历史等旁挂状态；图和元数据都不允许成为代码之外的第二真相源，用户随时可以脱离本工具继续开发。

## Considered Options

- **图即程序**（n8n / ComfyUI 模式）：把用户锁进私有格式，与「打开任意现有工程」的定位根本冲突，否决。
- **图与代码双向同步**：两个真相源必然漂移，否决。

## Consequences

图上的一切编辑动作（拖拽、Ghost Node、连线）最终都必须落成真实代码修改，没有捷径。
