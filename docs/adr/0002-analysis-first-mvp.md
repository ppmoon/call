# MVP 主打存量工程分析，生成是配角

首发竖切是「打开已有工程 → 从入口构图 → 下钻 → 在节点上指挥 AI 改码」，而不是空画布生成式编程；空工程只提供 hello-world 脚手架（带语言选择器，默认 Python）作新手引导。生成优先会正面撞上 Copilot/Cursor 的主战场，「秒懂存量工程 + 图上改码」才是差异点。

开发主线与 MVP 验收 = Wow Script（见 CONTEXT.md）：在 fixture 仓库上能一气呵成走完，MVP 才算完成。里程碑顺序 M0 骨架 → M1 构图 → M2 编辑 → M3 执行，全部由该剧本反推；剧本用不到的功能一律不做。M1 完成即发首个预览版（只读构图本身已有价值）。
