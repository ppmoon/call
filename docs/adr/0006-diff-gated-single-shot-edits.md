# AI 改码一律过 Diff Gate；v1 用单次调用管线，不用 agent 循环

任何 AI 产生的修改必须经 VS Code 原生 diff 审阅、accept 才落盘（同时把提示词记入 `.call/`），没有静默自动应用——这是对开发者用户的信任底线。编辑管线 v1 是单次 LLM 调用：目标函数源码 + 上下游签名 + 精选仓库上下文一次拼进 prompt。节点已把改动范围天然限定住，单次调用便宜、快、可预期。

这是刻意偏离「默认上 agent 循环」的常规路径：agent 循环能力更强但慢、贵、不稳定，留给二期的跨函数重构场景。未来加「自动应用」开关或 agent 管线时，先重读本条再动手。
